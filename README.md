# APIMotoboy

Projeto pessoal desenvolvido em Java com o framework Spring Boot, voltado para a criação de uma API para auxiliar motoboys e entregadores na análise de corridas.

## Sobre o projeto

A API tem como objetivo calcular a rentabilidade de uma corrida antes que ela seja realizada, permitindo ao entregador analisar informações como:

- Distância da corrida;
- Consumo médio da motocicleta;
- Preço do combustível;
- Valor recebido pela corrida;
- Custo estimado de combustível;
- Lucro líquido após o combustível;
- Lucro líquido por quilômetro;
- Comparação com o valor mínimo de lucro por quilômetro definido pelo próprio entregador.

A proposta é fornecer informações para que o próprio entregador possa tomar sua decisão sobre uma corrida com base nos seus custos e critérios pessoais.
